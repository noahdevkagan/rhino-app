# Rhino AppSumo submission handoff

Send the entire `Rhino-AppSumo-submission` folder to the person completing the AppSumo partner editor.

- `Rhino-AppSumo-submission-packet.docx` contains every field, pricing instructions, FAQs, screenshots, and the final checklist.
- `Rhino-AppSumo-submission-packet.pdf` is a read-only reference copy of the same 12-page packet.
- `appsumo-listing.md` and `appsumo-media-plan.md` contain the source copy and file-by-file upload plan.
- `assets/` contains the exact image files to upload.

Important: select **Codes**, not Licensing. Set **1 code to $5** and the **maximum code count to 1**. Do not publish until the code-redemption system passes an end-to-end test with a real AppSumo code.
